# GPUI desktop client

`packages/desktop-gpui` is the Rust GPUI desktop client, a Cargo workspace. It replaces the Electron renderer for daily use ([ADR-0034](../watchtower/decisions/ADR-0034-rust-gpui-client-over-swift-and-electron.md)). It talks to the unchanged TypeScript daemon over the WebSocket protocol. It only connects to a running daemon; Electron and the CLI keep daemon start, stop, updates, and deep links ([ADR-0041](../watchtower/decisions/ADR-0041-gpui-client-connects-only-over-daemon-management.md)). One window shows one host, over a plain `ws://` URL ([ADR-0040](../watchtower/decisions/ADR-0040-one-host-plain-ws-over-merged-hosts-and-relay.md)).

The Electron app is the visual reference. Each view crate names the Electron component it copies in its `lib.rs` header; read that header and the Electron source before you change a view.

## Layout

| Path                  | What it holds                                                                                                                                                          |
| --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `crates/*`            | Host crates, one per area                                                                                                                                              |
| `plugins/<plugin-id>` | Native plugin clients, `bachuc-plugin-<plugin-id>` ([plugins](plugins.md#gpui-native-clients))                                                                         |
| `vendor/gpui-base`    | Patched gpui-base ([ADR-0044](../watchtower/decisions/ADR-0044-vendored-gpui-base-patch-over-git-fork-or-log.md)); re-apply `BACHUC-PATCH.md` on each gpui-kit upgrade |
| `docs/`               | `a11y-audit.md`, `parity-audit.md`, and Electron-vs-GPUI screenshots in `parity/`                                                                                      |
| `cargo.sh`            | Runs cargo with the pinned rustup toolchain                                                                                                                            |
| `bundle.sh`           | Builds a release binary or example into `target/bundles/<name>.app`                                                                                                    |
| `measure.sh`          | Samples CPU and memory of process groups                                                                                                                               |

## Crates

The dependency graph runs one way: `protocol` -> `client` -> view crates -> `app`. Plugin crates sit beside the view crates and never depend on them.

| Crate         | Role                                                                                                                                                                                                                                                                                                |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `protocol`    | Wire types generated by `build.rs` from the zod schemas ([ADR-0035](../watchtower/decisions/ADR-0035-generated-protocol-types-over-hand-written-rust-types.md))                                                                                                                                     |
| `client`      | `Client` entity: one daemon connection, synced agents, workspaces, timelines, and RPCs                                                                                                                                                                                                              |
| `theme`       | Electron tokens for `light` and `claude` dark, zoom, syntax colors ([ADR-0043](../watchtower/decisions/ADR-0043-electron-tokens-and-lucide-icons-over-gpui-kit-defaults.md))                                                                                                                        |
| `icons`       | Lucide icons and provider logos, generated by `codegen/*.mjs`                                                                                                                                                                                                                                       |
| `plugin-host` | `NativePlugin` trait and contribution kinds for plugin crates ([ADR-0045](../watchtower/decisions/ADR-0045-native-rust-plugin-clients-over-webview-panes-or-shared-logic.md))                                                                                                                       |
| `workspace`   | Tab groups in resizable splits; it does not know pane kinds                                                                                                                                                                                                                                         |
| `sidebar`     | Left sidebar tree: nav rows, pinned workspaces, projects                                                                                                                                                                                                                                            |
| `timeline`    | One agent's timeline as a virtualized list of turn step lists                                                                                                                                                                                                                                       |
| `diagram`     | Mermaid through Pele on QuickJS and resvg ([ADR-0067](../watchtower/decisions/ADR-0067-pele-on-quickjs-over-hidden-webview-mermaid.md)); KaTeX as PNG snapshots from one hidden WebView ([ADR-0037](../watchtower/decisions/ADR-0037-hidden-webview-png-snapshots-over-svg-and-inline-webviews.md)) |
| `composer`    | Message box, pills, tracks, queue, attachments, slash and mention menus                                                                                                                                                                                                                             |
| `explorer`    | Files and Changes sidebar, file viewer, diff viewer, git actions, PR view                                                                                                                                                                                                                           |
| `terminal`    | Daemon terminal drawn with `alacritty_terminal`, restored from the JSON grid ([ADR-0042](../watchtower/decisions/ADR-0042-json-grid-terminal-restore-over-ansi-snapshot.md))                                                                                                                        |
| `command`     | Command center and the Electron shortcut table                                                                                                                                                                                                                                                      |
| `history`     | History screen                                                                                                                                                                                                                                                                                      |
| `settings`    | Settings screen                                                                                                                                                                                                                                                                                     |
| `app`         | Binary `bachuc-desktop`: window shell, panes, toasts, plugin registration                                                                                                                                                                                                                           |
| `prototype`   | Original `bachuc-gpui` prototype; not part of the app                                                                                                                                                                                                                                               |

Data flow: the socket runs on its own thread in `client/src/connection.rs` and hands events to the `Client` entity in batches. Views hold an `Entity<Client>`, read its state, and emit events; `app/src/shell.rs` routes those events between views. The timeline sync work stays in proportion to the change, never to the turn length ([ADR-0039](../watchtower/decisions/ADR-0039-incremental-timeline-sync-over-throttle-or-budget.md)).

When the protocol changes, run `crates/protocol/codegen/export-schema.mjs` to refresh `protocol.schema.json`. Generated names come from message tags; read them in `target/debug/build/bachuc-protocol-*/out/protocol.rs`.

## Build, run, and test

Run every cargo command through `./cargo.sh`, and follow the cleanup rules in [CLAUDE.md](../CLAUDE.md#critical-rules).

```bash
cd packages/desktop-gpui
./cargo.sh test -p bachuc-timeline
./bundle.sh bin bachuc-desktop "Bachuc GPUI" io.github.hieppp.bachuc-desktop
```

- The app reads hosts from `~/Library/Application Support/BachucGpui/hosts.json` and opens the host named `live`, or the one in `BACHUC_HOST`. Start live before a check ([development](development.md)).
- `BACHUC_WINDOW=900x800` sets the window size. `BACHUC_NO_ACTIVATE=1` with `open -n -g` keeps the app in the background.
- Build a check app under its own bundle name, so it never replaces the owner's running GPUI app.
- Each `-p` crate test gets its own gpui-kit build. Test a few crates in one command, and clean up after.
- Do not enable the gpui-kit `test-support` feature or the tree-sitter `css`, `html`, `toml`, or `yaml` features. They break workspace resolution.
- If parallel builds leave a duplicate entry in `Cargo.lock`, check it with `./cargo.sh metadata` before you commit.

## Daily app

`scripts/gpui-release.sh` builds the bundle, sets `BACHUC_HOST=release` in its `LSEnvironment`, signs it, installs it as `/Applications/Bachuc GPUI.app`, and opens it. It quits the running app with `SIGTERM` only after the build, and stops if the app has not quit after 60 s. `--skip-build` installs the bundle already in `target/bundles`. The script never stops the daemon, so agents keep running and it can run inside Paseo. The `bachuc-gpui-build` alias in `~/.zshrc` runs it.

- The GPUI app does not start the daemon (ADR-0041). The script installs the login item `io.github.hieppp.bachuc-daemon`, which runs `paseo daemon start` at login. Its log is `~/Library/Logs/Bachuc/daemon-login.log`.
- The login item runs through a login shell, because agents need the user's PATH. The Electron app gets the same env from `login-shell-env.ts`.
- Keep `/Applications/Bachuc.app` installed. The daemon and the `paseo` CLI run on its runtime, and `scripts/paseo-release.sh` still updates them.
- Keep "Keep running after quit" on in the Electron app. If you open Electron and then quit it, it stops a daemon it started when that setting is off.

## Rules

GPUI view crates have no headless test context. Put each rule (clamp, fallback, guard, threshold) in a pure function and test it; read-check the view code; then run a screen check. A layout rule on the wrong element passes every crate test.

Render path:

- Keep list items small: one per header and per step, never a whole turn.
- Never read a `ListState` in a row callback. It panics with "already mutably borrowed".
- Never query the system in a render path. `all_font_names` in a row draw made the timeline scroll lag.
- Prefer sorted vectors over small `HashMap`s on per-frame paths.

Layout:

- GPUI's default line height is 1.618; the browser's is 1.2. Set the line height on every text you match to Electron.
- The window rem is 16 x zoom, not the 14 px body font. Convert fixed px with `zoomed`, and apply zoom to width thresholds too, not only to sizes.
- Never toggle `display` from hover or `group_hover`. It panics with "must call prepaint before paint". Hide by opacity.
- Margins can collapse; add spacing with padding or offsets. Never put a negative main-axis margin on a child of a content-sized flex row.
- Put `min_w_0` and shrink on the real flex item. For a gpui-component `Popover`, style the trigger with `trigger_style`.
- gpui-kit `Input::h` shadows `Styled::h`.

Focus and accessibility:

- Give every pressable element an explicit `AccessibleAction::Click` handler, or an AX press does nothing.
- Give every `track_focus` element a role. Make a Tab stop with `cx.focus_handle().tab_stop(true)`; `.focusable()` alone is not one.
- `Entity::cached` views drop out of the AX tree.
- A right-click-only menu cannot be opened by a UI checker. Give each menu a keyboard or AX path.

Events and code:

- GPUI calls subscribers in subscription order. A shell handler that needs a later view's state for the same event uses `cx.defer_in`.
- A button drawn on top of a clickable row also sends its click to that row. Call `cx.stop_propagation()` in the button's handler, or `.occlude()` the button. The sidebar project "+" toggled its project until it stopped the click.
- GPUI holds a `cx.subscribe` emitter weakly. Dropping the last `Entity<Client>` stops its socket thread.
- In a file with `use gpui_kit::*`, a test module with `use super::*` picks up GPUI's `#[test]` macro. Import the needed items by name.
- When you add struct fields that cross crates, update every literal in other crates, and add the `lib.rs` export.
- Before you plan a client reaction to a daemon event, read the server send path. The daemon sends `remove` for an archived agent, not an upsert. When a daemon item is missing, check the client hello capabilities first.

## Screen checks

Screen checks run with `cua_repl` only and never take the cursor or the foreground.

- GPUI stops drawing while its window is covered. Raise the window with the AX `Raise` action before each screenshot, and navigate with `cmd+k`.
- Wrap each `cua_repl` call in a timeout. One hung call held the shared screen lock for 3 hours.
- Hover, trackpad gestures, right-click menus, and frame-level animation timing need the owner's hand check. Plan them as owner checks from the start.
- Measure CPU with `measure.sh` against a no-content control, at two turn ages.
