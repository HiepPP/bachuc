## Contract

- `bachuc_command::Shortcut { action: String, label: String, chord: Option<String> }`, as in the spec.
  - `chord` is the Electron combo string in Electron's own spelling, for example `Cmd+Shift+P`. A multi-key chord is the combos joined by one space. Parsing is case-insensitive and also accepts `Mod`, `Meta`, `Control`, `Option`. Planner example `mod+shift+p` parses too.
  - `action` is the Electron action name. Electron keys overrides by binding id, which is not unique per action, so the two relative-navigation actions get `.prev` and `.next`, and the two message-input actions are `message-input.focus` and `message-input.mode-cycle`.
- `default_shortcuts() -> Vec<Shortcut>`: 29 actions, Electron macOS defaults, in help-section order.
- `load_shortcuts() -> Vec<Shortcut>` and `save_overrides(&[Shortcut]) -> anyhow::Result<()>` read and write `~/Library/Application Support/BachucGpui/shortcuts.json`. `load_shortcuts_from(dir)` and `save_overrides_to(dir, ..)` take a folder (tests).
  - A missing key is the default. `null`, `""`, and whitespace are unassigned (`chord: None`). A non-string value or an unparsable string keeps the default. A corrupt or non-object file gives the defaults and is never rewritten.
  - `save_overrides` writes only chords that differ from the defaults (so "reset" removes the key), through a temp file and a rename. Unknown actions are ignored.
- `CommandItem { id: String, title: SharedString, group: SharedString, icon: Option<IconName>, shortcut: Option<String> }`. `shortcut` is a combo string.
- `CommandCenter::new(items, window, cx) -> CommandCenter`: a view that draws the backdrop and panel absolutely over its parent (`size_full`). Put it as the last child of a `relative` full-window element. It focuses its search input on creation.
- `CommandEvent::Run { id }` and `CommandEvent::Dismissed`. The view never closes itself: the owner drops it after either event. Enter or a click on a row emits `Run`; Escape or a click on the backdrop emits `Dismissed`.
- Extras for TASK-153 and TASK-155:
  - `gpui_keystrokes(chord) -> Vec<String>`: strings for `KeyBinding::new`, for example `shift-cmd-p` or `cmd-k cmd-b`. `Cmd+Alt+Digit` gives nine strings for 1 to 9 (index = position + 1). An invalid chord gives an empty vec.
  - `display_combos(chord) -> Vec<String>`: macOS glyph text per combo (`["⇧⌘P"]`, `Digit` shows `1-9`).
  - `is_valid_chord(&str) -> bool`.
  - `CommandCenter::set_items(items, cx)`, `focus(window, cx)`, `query(cx)`.
  - `bachuc_command::search::{SearchIndex, Layout, Row, step}` (the search model).

## Context-only bindings

Electron scopes these bindings; here they are all global, and the app (TASK-155) decides when to skip them:

- Disabled while the palette is open in Electron (`commandCenter: false`): every kept action except `command-center.toggle`, `sidebar.toggle.left`, `message-input.mode-cycle`, and `agent.interrupt`. The app should not run those shortcuts while a `CommandCenter` is shown.
- Disabled in an editable text surface (`editable: false`): `workspace.pane.focus.left/right/up/down`.
- Focus scope `message-input`: `message-input.mode-cycle` (`Shift+Tab`).
- Focus scope `message-input` or `other` (not a terminal): `agent.interrupt` (`Escape`).
- Desktop only: `workspace.tab.close.current`, `workspace.tab.navigate.index`, `workspace.navigate.prev/next`.

## Lessons

- The palette reads Up, Down, and Escape through `App::intercept_keystrokes`, because the single-line `Input` binds Up and Down (context `Input`) and wins over a binding on a parent context. The interceptor runs only while the input has focus and stops propagation for the keys it handles. Enter comes from `InputEvent::PressEnter`.
- A view that takes no keystrokes outside the palette needs no key context. TASK-155 must keep its own shortcut dispatch from also handling `Escape` while the palette is up; the interceptor stops propagation first, so a `KeyBinding` for `escape` does not fire while the input has focus.
- `gpui::list` takes `ListState::reset(n)` when the row count changes. The `list` element has no `.id()` or `.role()`; wrap it in a `div` for the AX label.
- Hint text uses `Kbd::format` (gpui-kit's macOS glyph formatter) inside a div styled as the Electron badge, because `Kbd` cannot show the `Digit` wildcard as `1-9`.
- I edited one file with a Python one-liner by mistake (`search.rs`, a sort tie-break and a test helper). The change is in place and tested; no other file was changed that way.
