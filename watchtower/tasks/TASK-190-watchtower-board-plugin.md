- RPCs, camelCase JSON: `watchtower.read {workspaceId}` -> `Board`; `watchtower.project.read {projectId}` -> `Board`; `watchtower.overview.read {workspaceId}` -> `Overview`; `watchtower.decision.read {workspaceId, id}` -> `{id, title, status, file, markdown}`. `watchtower.search` is called by the host picker through `AttachmentPicker::search_method`. Every nullable field decodes to `Option`; an unknown task `status` stays a string.
- Load rules copy Electron: board and overview load once per workspace and again only on Refresh; the pill reuses a cached board younger than 30,000 ms. Load after `ClientEvent::Connected` and again after each reconnect. The store observes the plugin host's active workspace and loads its board when the cache is missing or stale, so the pill `state` closure only reads.
- Planner call: GPUI keeps agents live in `Client::agents()`, so builder matching and the agent target read client state and recompute on `ClientEvent::AgentsChanged`; the two 15 s agent polls of Electron are dropped. A candidate takes `AgentSummary` (`id`, `title`, `status`, `workspace_id`, `provider`, `pending_permissions`), `Client::agent_labels` (`watchtower.task`, `paseo.parent-agent-id`), `Client::agent_attention` (the `permission` reason), and `Client::agent_updated_at`. Archived agents are already absent from the client.
- `choose_agent` and `match_builders` sort by `agent_updated_at`, newest first, as Electron sorts by `updatedAt`; an unreadable time sorts last. `active_ago` is now minus `agent_updated_at`, or `None` when unreadable, which TASK-194 shows as "active N ago".
- `send` calls `choose_agent` again, then `Client::send_message` with `OutgoingMessage { text, images: vec![], attachments: vec![] }` and `TurnBehavior::Interrupt`, the daemon default. "No agent in this workspace." and "Agent busy." are errors, as in `agent-target.ts:49-50`.
- Workspace choice: `params.workspaceId`, else the preselected workspace, else `PluginContext::active_workspace_id`, else the first of `Client::workspaces()`. A named workspace never falls back to another one; one missing from the client shows "Workspace not found.". Placeholders copy `page.tsx:46-65`. The project name is the `ProjectNode::name` that holds the workspace.
- Surface params (lead, from the spec check): the `watchtower` surface reads `params.task` as the initial task id, as Electron does (`client/page.tsx:18,74`). The store keeps it, and TASK-194's page selects that task once it loads.
- Contribution rules: the shortcut uses `combo: "Mod+G"` and `surface: Some("watchtower")`, so the host toggles the overlay closed when it is open (TASK-174). A press with no workspace does nothing; otherwise it preselects the workspace and calls `open_surface("watchtower", OpenSurfaceOptions { presentation: Overlay, .. })`. The Command Center item (context `Workspace`) does the same. The pill (`Track`, `ShowOnDraft::Yes`) has title "Open Watchtower", icon `IconName::ListTodo`, label "Watchtower" on a draft else `pill_label(board, live)`, and `PillBehavior::Action` with `new_workspace_panel: Some("board")`; a press on an agent composer preselects its workspace and opens the overlay. The attachment source is `tasks` "Watchtower task" with picker title "Attach Watchtower task", the Electron placeholder, and `search_method: "watchtower.search"`.
- New workspace panel `board`: `watchtower.project.read` for the panel's project, the header "<project> · Read-only" with Refresh, then `ProgressCard`, warnings, `WaitingCard`, and `TasksCard` with `dense` and the done group collapsed. The project name is the last path segment of `cwd`.
- Task list: "Copy attachment search" writes `attachment_key(workspace, task)` with `cx.write_to_clipboard` and shows Electron's success or failure notice.
- Look: tokens from `bachuc_theme` with Electron's names (`surface0`, `surface1`, `surface2`, `foreground`, `foreground_muted`, `border`, `accent`, `accent_foreground`, `status_success`, `status_warning`, `status_danger`); `MONO` is `bachuc_theme::mono_font_family`. Copy the measures in Design line by line: cells radius 12 and padding 14, task rows radius 6, badge radius 5, progress strip 6 px, `ShowMore` limit 5.

Expected result:

- With watchtower-board listed enabled and `Running`, every agent composer shows the pill "Watchtower D/N[, R running][, Q questions]", and a draft composer shows "Watchtower" and opens the `board` New workspace panel.
- `Mod+G`, the pill, and "Open Watchtower board" open the overlay on the right workspace, which shows the rail cards for now; the attachment picker lists tasks through `watchtower.search`.
- Cases:
  - `pill_label(None)` -> "Watchtower"; 3 of 5 done, 1 live not-done, 1 question -> "Watchtower 3/5, 1 running, 1 question"; a live DONE task is not counted.
  - `parse_markdown`: headings, nested bullets by two spaces, a `~~~` fence, an unclosed fence that flushes, and paragraph lines joined with "\n".
  - `task_group` for each status; `task_title` strips "TASK-12: " and falls back to the full title when only the id remains.
  - `choose_agent`: no own agent -> `NoAgent`; all running or initializing -> `Busy`; a subagent and a `mock` provider are skipped; the newest `agent_updated_at` wins; the name falls back to the id.
  - Prompt builders match the Electron strings, with trailing periods stripped from answers.
  - `lifecycle_phases`: ARCHIVED -> Archive; no tasks -> Plan; finished run -> Review; all DONE -> Verify; else Implement.
  - `needs_you` order: blocking questions, other questions, proposed ADRs, then one manual-checks row; a default of "", "-", or "none" counts as none.
  - `match_builders`: a group label covers the group; a TASK id label covers its group; `standalone` is no group; a pending permission -> waiting; the lead is the most named parent; `active_ago` from `agent_updated_at`, `None` when unreadable.
  - `build_plan_tree` and `build_timeline`: the ported `plan-tree` and `timeline` tests, including a dependency cycle in the last wave.
  - `clock_at` with a run that started at 23:50 and minute 20 wraps to "00:10"; an unreadable start -> `None`.
  - `commit_shas` finds the first 7-40 hex run with a digit and keeps 7 chars.
  - `attachment_key("w1", "TASK-3")` -> "workspace:w1 TASK-3".
  - Workspace choice: a named workspace missing from the client -> "Workspace not found.", never another workspace.

Anti-goal: the pill causes no request storm: across 100 redraws of a composer for one workspace, the store sends at most one `watchtower.read` and one `watchtower.overview.read` per 30,000 ms, and the pill state closure sends none; tripwire; read from the `cache_fresh` and in-flight guard tests when the store lands and at completion.
