## Brief

Change: the GPUI client has no code for these six plugins -> six crates `bachuc-plugin-<id>`, each with `pub fn plugin()` and tested pure rules.

Boundaries:

- Follows [ADR-0045](watchtower/decisions/ADR-0045-native-rust-plugin-clients-over-webview-panes-or-shared-logic.md): each client part is native Rust, and the server parts in `hiep-plugins/plugins/<id>` stay unchanged.
- Each crate lives in `packages/desktop-gpui/plugins/<id>`, is named `bachuc-plugin-<id>`, and exports only `pub fn plugin() -> Box<dyn bachuc_plugin_host::NativePlugin>` to the app. Its `id()` is the plugin id, for example `"stop-orb"`.
- Each crate depends only on `bachuc-plugin-host`, `bachuc-client`, `bachuc-theme`, `bachuc-icons`, `gpui-kit.workspace = true` with no `features` key, and small crates (`serde`, `serde_json`, `anyhow`, `log`, `form_urlencoded`). It never depends on a view crate (`bachuc-composer`, `bachuc-sidebar`, `bachuc-timeline`, `bachuc-command`, `bachuc-settings`, `bachuc-workspace`, `bachuc-explorer`, `bachuc-app`).
- Hold every entity, task, and subscription in state that a contribution closure captures, so deactivation drops it ([TASK-170](watchtower/tasks/TASK-170-plugin-host-crate-and-registry.md) Boundaries: cleanup is by `Drop`).
- Put each rule in a pure function and test it; GPUI view crates have no headless test context (`MEMORY.md`, 2026-10-16). New views use `bachuc_theme` tokens and metrics and `bachuc_icons` icons.
- claude-look (owner): port only the palette, as one `ThemeContribution` with id `claude-light`, name `Claude Light`, `ThemeAppearance::Light`, and the eight colors of `theme.ts`. Port no web CSS and no width change.
- stop-orb (owner): draw the `solving` orb as a GPUI animation, not a WebView. Port `frameRubik` and its helpers as pure functions that return the sorted dot list of one frame. Paint each dot as a filled circle on a `canvas`.
- stop-orb sizing: the sphere diameter is `StopButtonProps::icon_size`; pick the preset and scale with `solvingOrb`. Apply `dotSize` 1.4 through `scaleRadii`. The frame time is seconds times the preset speed times a multiplier: 1, or 1.8 while hovered and not cancelling. Freeze the frame while `cancelling`. Request the next frame only while the button shows and is not cancelling.
- stop-orb color: tint with the stop button red `#dc2626`, the same value as `STOP_RED` in `crates/composer/src/composer.rs:43`, kept as a named constant (see Literal colors). Pick dark ink from `bachuc_theme::scheme(cx)`, not from a surface color.
- stop-orb hover: the face gets the `surface2` background on hover, as the composer's other icon buttons do. Change only the background and speed on hover; never toggle `display` (CONTEXT GPUI lessons). Keep one face entity per agent id in a map, and return it from `StopButton::render`.
- idle-runtime-closer (owner): keep the pill hidden, as Electron does with `visible: false`. Its `state` closure returns `None` while the crate constant `SHOW_PILL` is `false`. Keep the press rule so that flipping `SHOW_PILL` shows a working pill: refresh the agent, refuse it when it is `running` or `initializing` or has pending permissions, else close its runtime. A refusal or failure shows the Electron text (`index.client.tsx:18-24`) with `show_message(.., MessageLevel::Error, ..)`, as the Electron pill toast does.
- plugins-nav: add the sidebar item `plugins`, title `Plugins`, icon `Blocks`, surface `plugins`, and an action that calls `PluginContext::open_plugins_page`. Add a `Surface` `plugins` whose view is empty, as Electron registers one (`index.client.tsx:7`).
- thread-context-attach: add the attachment source `thread`, title `Thread`, icon `IconName::MessagesSquare`, with an `AttachmentPicker` whose `search_method` is `thread-context.search`. The picker title is "Attach another thread's last reply" and the placeholder is "Search threads by title, provider, or folder" (`shared/threads.ts:57-58`; lead, from the spec check). The client calls no other RPC; `thread-context.list-threads` and `thread-context.get-thread-snapshot` stay server-only.
- assistant-cite: add the chip-only attachment source `quote`, title `Quote`, with no picker and an `on_open` that reveals the passage. Add the selection action `cite`, title `Cite`, that builds the quote item and calls `add_composer_attachment` with `commentable: true`.
- assistant-cite item fields (lead, from the spec check): `identifier` is `"reply"` and `resourceType` is `"quote"`. The title is the first 8 words of the quote, cut at 60 characters plus an ellipsis (`shared/item.ts:55-61`). `parse_quote_item` returns `None` without a `message` param (`shared/item.ts:72`).
- assistant-cite wire match: a chip made in GPUI must open in Electron, and the reverse. So the item `url` is `paseo-cite://quote?` plus `form_urlencoded` pairs `server`, `agent`, then `message` when present, as `URLSearchParams` writes them. The `id` is `<messageId or agentId>:<hash>`, where the hash is FNV-1a over the UTF-16 code units of the trimmed quote, with 32-bit wrapping multiply, written in base 36. `MAX_QUOTE_LENGTH` (4000) counts UTF-16 code units, as JS `length` does.
- assistant-cite server id: read it from `Client::server_info()` (`server_id`). Planner call: `on_open` reveals the passage only when the chip's `server` equals the active host's server id; a chip from another host does nothing. An over-long quote adds no chip and logs a warning, as Electron does.
- Icons (lead decision): use the real icons `IconName::Quote`, `IconName::MessagesSquare`, and `IconName::Power`, which TASK-195 adds. This TASK also depends on TASK-195.
- Literal colors (Planner call): a color with no `bachuc_theme` token is a named constant with a comment that cites its Electron source `path:line`, as `STOP_RED` in `crates/composer/src/composer.rs:43` does. Here that is only the stop-orb red (`hiep-plugins/plugins/stop-orb/client/stop-orb.tsx:8`).
- The app registers these crates in TASK-191, so no screen shows them before then.
