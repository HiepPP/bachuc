# TASK-303 Pele engine, theme vars, resvg PNG

Group: A (writes `crates/diagram/Cargo.toml` and `src/lib.rs`, shared with TASK-301 and TASK-304)
Class: risky

## Brief

Goal: Add a background engine that turns Mermaid source into a themed 2x PNG with Pele, QuickJS, and resvg, without touching the main thread.

Change: no native Mermaid path -> `PeleEngine` on its own thread, plus pure functions to resolve CSS vars and rasterize SVG.

Boundaries:

- Follows ADR-0067 from TASK-302: Pele on QuickJS, vendored with `include_str!`, 2x PNG through resvg.
- This TASK adds modules only. `DiagramRenderer` does not use them yet; TASK-304 wires them.
- Planner call: add `resvg = { version = "0.46", default-features = false, features = ["text", "system-fonts", "memmap-fonts"] }`. This reuses the 0.46.0 build that GPUI already pulls.
- When every `PeleEngine` handle is dropped, the job channel closes and the engine thread ends. A reply to a dropped receiver is ignored.
- The PNG keeps the SVG's own width and height times 2, so `image_size` gives Pele's size. There is no fixed 960 px box any more.
- Run Pele, `resolve_vars`, and `rasterize` on the engine thread. Never on the GPUI main thread.
- Create the QuickJS `Runtime` and `Context`, load Pele, and load system fonts into one usvg fontdb once, on the engine thread. Set the fontdb sans-serif family to `Helvetica Neue`.
- Trap: `pele.render` in QuickJS: a JS exception arrives as `rquickjs::Error::Exception`. Read the message with `Ctx::catch`, so `Failed` shows Pele's text, not "Exception generated by QuickJS".
- Trap: `rquickjs::Runtime` is not `Send` without the `parallel` feature. Create it inside the thread; do not move it into the thread.
- Planner call, theme mapping from `bachuc_theme::Tokens`: bg `surface0`, fg `foreground`, muted `foreground_muted`, line `foreground_muted`, surface `surface1`, surface-alt `surface2`, border `border`, accent `accent`, series 1 to 8 `ansi[4]`, `ansi[2]`, `ansi[3]`, `ansi[1]`, `ansi[5]`, `ansi[6]`, `ansi[12]`, `ansi[10]`, font `Helvetica Neue, Helvetica, Arial, sans-serif`, mono font `Menlo, monospace`.
- Planner call, color text: `#rrggbb` when alpha is 1, else `rgba(r,g,b,a)` with `a` rounded to 3 decimals.
- Planner call, unknown names: a `var()` that names no theme property and has no defined private value resolves to its own fallback; with no fallback it resolves to the theme fg.

How:

- Add `src/svg.rs` with `PeleTheme`, `pele_theme`, `resolve_vars`, and `rasterize`.
- Add `src/pele.rs` with `PeleEngine`: one thread, an mpsc job channel, and one `oneshot` reply per job.
- Add `rquickjs` (already from TASK-301), `resvg`, and `bachuc-theme = { path = "../theme" }` to `Cargo.toml`.
- Add `mod pele;` and `mod svg;` in `lib.rs`.

Expected result:

- WHEN `resolve_vars` gets a Pele SVG THE function SHALL return an SVG with no `var(` left, where each Pele property takes the theme value.
- WHEN `rasterize` gets an SVG of width W and height H THE function SHALL return a PNG of 2W by 2H pixels.
- WHEN `render_png` gets a valid flowchart THE engine SHALL reply with PNG bytes.
- IF Pele throws on the source THEN THE engine SHALL reply `Err` with Pele's error text.
- IF the source is over Pele's size limit THEN THE engine SHALL reply `Err` and keep serving the next job.

File: [packages/desktop-gpui/crates/diagram/src/svg.rs](packages/desktop-gpui/crates/diagram/src/svg.rs)

```rust
#[cfg(test)]
mod tests {
    use super::*;

    fn theme() -> PeleTheme {
        let mut theme = pele_theme(&bachuc_theme::Tokens::claude_dark());
        theme.fg = "#e6e6e6".into();
        theme.line = "#808080".into();
        theme
    }

    #[test]
    fn private_vars_resolve_through_the_theme() {
        let svg = r#"<svg style="--_fg:var(--pele-fg,#1f1f1f);--_l:var(--pele-line,#1f1f1f);color:var(--_fg)" fill="var(--_fg)"><path stroke="var(--_l)"/></svg>"#;
        let out = resolve_vars(svg, &theme());
        assert!(!out.contains("var("), "{out}");
        assert!(out.contains(r#"fill="#e6e6e6""#), "{out}");
        assert!(out.contains(r#"stroke="#808080""#), "{out}");
    }

    #[test]
    fn unknown_names_use_their_fallback_or_the_fg() {
        let out = resolve_vars(
            r#"<svg><path fill="var(--pele-unknown,#123456)"/><path fill="var(--_nope)"/></svg>"#,
            &theme(),
        );
        assert!(out.contains(r#"fill="#123456""#), "{out}");
        assert!(out.contains(r#"fill="#e6e6e6""#), "{out}");
        assert!(!out.contains("var("), "{out}");
    }

    #[test]
    fn rasterize_returns_a_png_at_twice_the_size() {
        let png = rasterize(
            r#"<svg xmlns="http://www.w3.org/2000/svg" width="10" height="5"><rect width="10" height="5" fill="#ff0000"/></svg>"#,
        )
        .expect("png");
        let read = |at: usize| u32::from_be_bytes(png[at..at + 4].try_into().unwrap());
        assert_eq!((read(16), read(20)), (20, 10));
    }

    #[test]
    fn colors_with_alpha_resolve_to_rgba_that_usvg_reads() {
        let mut theme = theme();
        theme.surface = "rgba(255,0,0,0.5)".into();
        let out = resolve_vars(
            r#"<svg xmlns="http://www.w3.org/2000/svg" width="4" height="4" style="--_s:var(--pele-surface,#f3f3f3)"><rect width="4" height="4" fill="var(--_s)"/></svg>"#,
            &theme,
        );
        assert!(out.contains("rgba(255,0,0,0.5)"), "{out}");
        assert!(rasterize(&out).is_ok());
    }
}
```

```rust
#[cfg(test)]
mod tests {
    use super::*;
    use crate::svg::pele_theme;
    use futures::executor::block_on;

    fn theme() -> crate::svg::PeleTheme {
        pele_theme(&bachuc_theme::Tokens::light())
    }

    #[test]
    fn valid_flowchart_gives_png_bytes() {
        let engine = PeleEngine::spawn();
        let png = block_on(engine.render_png("flowchart LR\n  A --> B".into(), theme()))
            .expect("reply")
            .expect("png");
        assert_eq!(&png[1..4], b"PNG");
    }

    #[test]
    fn bad_source_gives_pele_error_text_and_the_engine_keeps_working() {
        let engine = PeleEngine::spawn();
        let error = block_on(engine.render_png("flowchart LR\n  A --> (".into(), theme()))
            .expect("reply")
            .expect_err("parse error");
        assert!(!error.is_empty());
        assert!(!error.contains("Exception generated by QuickJS"), "{error}");
        // Read the source limit constant in pele.global.js and go one character over it.
        let huge = format!("flowchart LR\n{}", "  A --> B\n".repeat(PELE_SOURCE_LIMIT / 10 + 1));
        assert!(block_on(engine.render_png(huge, theme())).expect("reply").is_err());
        assert!(block_on(engine.render_png("pie\n  \"a\" : 1".into(), theme()))
            .expect("reply")
            .is_ok());
    }
}
```
