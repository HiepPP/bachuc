# TASK-186 thread-branch plugin

Group: O (writes the new crate `plugins/thread-branch`; the tag comes from its own folder)
Class: code

## Brief

Goal: Port the thread-branch client to a native GPUI crate: the branch, PR, and changes pills on agent composers, the branch pill on New workspace, the turn diff card in the timeline, the Turn diff panel, its command, and the GitHub PR attachment source.

Change: GPUI shows no branch pills, no turn diff cards, and no Turn diff panel -> the crate `bachuc-plugin-thread-branch` contributes them and calls the unchanged server part through its RPCs.

Boundaries:

- Follows [ADR-0045](watchtower/decisions/ADR-0045-native-rust-plugin-clients-over-webview-panes-or-shared-logic.md): the server part in `hiep-plugins/plugins/thread-branch` stays unchanged. The crate calls it only through these RPCs:
  - `thread-branch.get`: input `{cwd, force?, fetch?}`, output `BranchInfo` (`repo`, `branch`, `detached`, `sha`, `dirty`, `changes: {files, added, deleted} | null`, `upstream`, `ahead`, `behind`, `pr: {number, url, state} | null`, `remoteUrl`, `prLookup`).
  - `thread-branch.turn-history`: input `{agentId}`, output `{turns: [{key, agentId, endedAt, diff}]}`.
  - `thread-branch.file-diff`: input `{root, from, to, path}`, output `{diff, truncated}`.
  - `thread-branch.file-image`: input `{root, from, to, path}`, output `{before, after, tooLarge}`, where `before` and `after` are `data:` URIs or `null`.
  - `thread-branch.search-prs`: called by the host picker with `{query}`; output `{items}`.
  - The timeline item `{kind: "thread-branch-turn-diff", version: 1, data: TurnDiff}` comes from the server part.
- The crate is `bachuc-plugin-thread-branch` in `packages/desktop-gpui/plugins/thread-branch`. It exports only `pub fn plugin() -> Box<dyn bachuc_plugin_host::NativePlugin>` with `id()` `"thread-branch"`. It depends on `bachuc-plugin-host`, `bachuc-client`, `bachuc-theme`, `bachuc-icons`, `gpui-kit.workspace = true` with no `features` key, `serde`, `serde_json`, `anyhow`, `log`, `chrono`, and `base64`, never on a view crate.
- Agent pills: three `ComposerPill`s, `thread-branch`, `thread-branch-pr`, and `thread-branch-changes`, with `ShowOnDraft::No` and `PillPlacement::Track` (Electron's default). Each `state` closure finds the target agent's `cwd` and `workspace_id` in `Client::agents()`. An agent with no workspace or no cwd gets no pills.
- Branch pill: title `pill_title`, label `pill_label` plus the ahead and behind counts (U+2191 and U+2193, zero counts left out), icon `GitBranch`. Its `color` is `None` when in sync, `accent` when ahead, and `status_warning` when behind (`syncState`). It hides when `repo` is false.
- Planner call (menu): `PillBehavior` has no menu kind, so the branch pill and the draft pill use `PillBehavior::Popover { flush: true, .. }` with menu rows drawn like the Electron pill menu. Rows: `Copy branch name` (shown when not detached and a branch exists), `Open <repo>` with ` on GitHub` for a GitHub remote (shown when `remoteUrl` is set), a divider, `Fetch` (shown when `upstream` is set), and `Refresh`. Each row has `Role::MenuItem` and a label. A press closes the popover.
- PR pill: shown when `repo` and `pr` are set; label `#<number>`; title `Open PR #<number> (<state lowercased>)`; icon `GitPullRequest`; an action that opens `pr.url`. Changes pill: shown when `repo`, `dirty`, and `changes` are set; label and title as `describeChangesPill`; icon `FileDiff`; an action that refreshes with `force`.
- Actions: copy writes to the clipboard (`ClipboardItem::new_string`); open calls `App::open_url`; refresh sends `{cwd, force: true}`; fetch sends `{cwd, fetch: true}`. A failure shows its error with `PluginContext::show_message(.., MessageLevel::Error, ..)`, as the Electron pill toast does (`packages/app/src/plugins/buttons/view.tsx:169-170`). The texts are those of `pills.ts:62-86` and `draft-pill.ts:48-52`, for example `No branch name to copy.`.
- Draft pill: id `thread-branch-draft`, `ShowOnDraft::Only`, `PillPlacement::Track` (the Electron default; lead, from the spec check), title `Git branch of the selected project`, icon `GitBranch`, label `draft_pill_label(draft cwd, info)`. Its menu holds `Copy branch name`, a divider, `Fetch`, and `Refresh`. The draft cwd is `ComposerDraft::cwd`.
- Planner call (loading): a pill `state` closure gets only `&App`. Keep `BranchInfo` per cwd in a crate store `Rc<RefCell<..>>`. When a cwd is missing and not in flight, start the read with `App::spawn`. Every 15 s, read again each cwd that a pill asked for while an agent or draft with that cwd still exists, one read per cwd. Call `PluginContext::notify` only when the `signature` of a cwd's info changes (`pills.ts:28-42`). A failed read keeps the last info. Hold the poll task in state that a contribution closure captures.
- Turn diff renderer: kind `thread-branch-turn-diff`, version 1. Port the card look of `turn-diff-card.tsx`: header, shared-turn warning, commit rows, file rows with the five-block bar, and the `and N more` footer. A file row opens the diff only when `source` is set and the file is not `large`. A press stores the selected file and calls `open_panel("turn-diff", PanelTarget { workspace_id: source.workspace_id, agent_id: Some(agent_id), location: None })`.
- Selected file: one crate store `Rc<RefCell<Option<FileSelection>>>`, shared by the cards and the panel, as `selection.ts` does. A card marks its row selected when the agent, `to`, and `path` match.
- Turn diff panel: id `turn-diff`, title `Turn diff`, icon `FileDiff`, `PanelContext::Agent`, `locations: vec![PanelLocation::Workspace]` (Electron's default). With no selected file for its agent, it shows `Changes by turn` from `thread-branch.turn-history`, read again every 15 s while it shows, with each turn's time and card. With a selected file, it shows the header (back link `All turns`, path, badge, counts, Wrap switch) and the diff rows from `thread-branch.file-diff`. An image path shows the before and after images from `thread-branch.file-image`.
- Panel rules: diffs and images are cached by root, from, to, and path for the panel's life, because snapshot trees never change. At most 2,000 rows show, then the too-long note. The Wrap switch starts on and keeps its last value for the session. The gutter width follows `gutterWidth`. Decode a `data:` URI with `base64` into a `gpui_kit::Image`.
- Planner call (time): the turn time uses local time in the form `Oct 16, 03:45 PM`, the en-US output of `formatTime`.
- Colors: markers use the `diff_addition` and `diff_deletion` tokens, which equal Electron's marker colors.
- Literal colors (Planner call): a color with no `bachuc_theme` token is a named constant with a comment that cites its Electron source `path:line`, as `STOP_RED` in `crates/composer/src/composer.rs:43` does. Here that is the two row tints `rgba(46, 160, 67, 0.15)` and `rgba(248, 81, 73, 0.1)` (`hiep-plugins/plugins/thread-branch/client/diff-colors.ts:4-5`).
- Command: id `open-turn-diffs`, title `Open turn changes`, icon `FileDiff`, `CommandContext::Agent`. It clears the selected file and opens the `turn-diff` panel for the input's workspace and agent; a missing workspace id does nothing.
- Attachment source: id `github-pr`, title `GitHub PR`, icon `GitPullRequest`, picker title `Attach an open pull request or its failed CI log`, placeholder `Search by repo, #number, title, or branch`, `search_method` `thread-branch.search-prs`.
- Icons (lead decision): use `IconName::CloudDownload`, `IconName::FileImage`, and `IconName::FileCode`, which TASK-195 adds. This TASK also depends on TASK-195. Uses (lead, from the spec check): `CloudDownload` is the `Fetch` menu row icon of the branch pill and the draft pill (`buttons.ts:64`, `draft-pill.ts:97`). `FileImage` and `FileCode` are the turn diff card file row icons, `FileImage` for an image path and `FileCode` for a text file, with the existing `File` icon when `added` is null (`turn-diff-card.tsx:178`).
- Never toggle `display` from hover; row hover changes only the background and the chevron color (CONTEXT GPUI lessons). Every new button, row, and switch has a role and a label.
- Every rule that does not need `App` is a pure function with a test (`MEMORY.md`, 2026-10-16).
- The app registers the crate in TASK-191, so no screen shows it before then.

Expected result:

- An agent composer in a git work tree shows the branch pill, with the PR and changes pills when they apply; the branch menu copies, opens, fetches, and refreshes.
- New workspace shows the draft branch pill for the selected project.
- A turn diff item in the timeline shows the card; a file press opens the Turn diff panel on that file's diff.
- Cases:
  - Every case of `tests/label.test.ts`, including detached heads, the 24-character cut, and the sync icon colors.
  - Branch label: ahead 2 and behind 0 with an upstream -> the name, a space, and the up arrow with 2; no upstream -> counts left out.
  - `repo: false` -> all three agent pills hidden; a clean tree -> no changes pill; no PR -> no PR pill.
  - `draft_pill_label`: no cwd -> `No project`; no info yet -> the U+2026 ellipsis; not a repo -> `Not a git repo`.
  - `parse_unified_diff`: an added file, a deleted file, a binary file, and a no-newline note -> the status, counts, and line numbers of the JS function.
  - `turn_diff_header`: zero files with commits; one file; several files with commits.
  - `image_type`: `a.PNG` -> `image/png`; `a.txt` -> `None`.
  - The bar blocks: 3 added and 1 deleted -> 4 add blocks and 1 remove block; 0 and 0 -> none.
  - A file row with no `source`, or a `large` file -> not pressable.
  - Two agents in one cwd -> one `thread-branch.get` per poll tick.
  - A poll answer with the same signature -> no notify.

Anti-goal: at most one `thread-branch.get` per distinct cwd per 15 s tick, and no redraw for an unchanged signature; tripwire; read from `poll_one_read_per_cwd` and `same_signature_no_notify` after the store lands and at completion.
