Boundaries:

- Follows [ADR-0045](watchtower/decisions/ADR-0045-native-rust-plugin-clients-over-webview-panes-or-shared-logic.md): native Rust client, unchanged server part, calls only through plugin RPCs.
- Crate `bachuc-plugin-board` in `packages/desktop-gpui/plugins/board`. It depends on `bachuc-plugin-host`, `bachuc-client`, `bachuc-theme`, `bachuc-icons`, `gpui-kit.workspace = true` with no `features` key, `serde`, `serde_json`, `anyhow`, `log`, and `chrono = { version = "0.4", default-features = false, features = ["std", "clock"] }` for local clock text. It never depends on a view crate or on another plugin crate. Its only public item is `pub fn plugin() -> Box<dyn bachuc_plugin_host::NativePlugin>`, with `id()` `"board"`.
- Split (lead, 2026-10-16): this TASK is part 1 of the board crate. It leaves `plugin()` complete and loadable; TASK-193 adds contributions to the same `contribute` and edits `src/page.rs` and `src/card.rs` at the seams named in Interfaces.
- RPCs, camelCase JSON: `board.snapshot {}` -> `{runs, observingSince}`; `board.set-starred {id, observingSince, starred}` -> `{updated}`; `board.remove-finished {id, observingSince, endedAt}` -> `{removed}`; `board.close-runtime {agentId}` -> `{closed, kept, failed}`; `board.edit-diffs.set {agentId, off}` -> `{}`. Settings through `PluginContext::settings`: `thinking-orb` `{enabled = true, state = "solving", avatarOpacity = 100}`, `project-colors` `{hues: {projectId: 0..359}}`, `board-size` `{size: 10..200 step 10 = 100}`. Decode each run on its own; a bad run is skipped and logged.
- Planner call: the Board shows one lane, for the active host, labeled `Client::host().name` with `.local` stripped. This follows [ADR-0040](watchtower/decisions/ADR-0040-one-host-plain-ws-over-merged-hosts-and-relay.md): the GPUI client connects to one host at a time and no view handles a merged host list. Electron's lanes for other hosts are not drawn.
- Planner call: one `BoardStore` per activation polls `board.snapshot` for the page and for TASK-193's pills together: on the cadence of `board_poll_interval` (`shared/board.ts:68-78`): every 2,000 ms while a run is running, every 15,000 ms when none is (lead, from the spec check), with one request in flight at most. A response is applied only when its JSON differs from the last one, so an unchanged poll causes no redraw; the receive time still updates. Load after `ClientEvent::Connected` and again after each reconnect.
- Connection state copies `boardConnectionState` with `BOARD_LIVE_WINDOW_MS = 10000`: disconnected -> `Offline`; last request failed -> `Error`; no data -> `Connecting`; data older than 10 s -> `Stale`; else `Live`. Snapshot warnings copy page 1512-1519.
- Card actions copy Electron: star calls `board.set-starred`; the diffs button calls `board.edit-diffs.set`; Remove runs `remove_finished_run` (remove; on `removed: false` re-read once and retry once with the fresh `observingSince`, per `remove.ts:4-23`), then `board.close-runtime`. Each failure shows its inline card error (page 860-886). The repo label calls `PluginContext::open_new_workspace` with `{cwd, projectId, name: project}`, or shows "Project directory is unavailable." without `cwd`.
- A card or subagent row click calls `PluginContext::open_agent_at(agent_id, AgentAnchor::LatestPrompt, cx)`, as Electron opens with `anchor: "latest-prompt"`. There is no hover prefetch.
- The TASK chip links to Watchtower only when the plugin host index has surface `("watchtower-board", "watchtower")` and the run has `workspaceId`. It calls `open_surface("watchtower", OpenSurfaceOptions { plugin_id: Some("watchtower-board"), presentation: Overlay, params: {workspaceId, task} })`, as `hosts.ts:19-26` does.
- Palette: after each applied snapshot, `allocate_colors(hues, project ids in runs)`; save `project-colors` only when the result differs, one save at a time. A failed save shows "Could not save project colors. Tap to retry.".
- Size: the size control saves `board-size` one write at a time, keeps the newest unsaved choice, and retries a failed value only after a new pick. `scale = size / 100 * 0.7`; every Runs measure multiplies by it.
- Shortcut: `Shortcut { id: "open-board", combo: "Mod+D", surface: Some("board"), .. }` opens the board with `open_surface("board", Default::default())`. GPUI binds no `cmd-d` today. `Mod+D` maps to Cmd+D, because the GPUI app runs on macOS only (lead, from the spec check).
- Avatars: the 20 PNGs in `hiep-plugins/plugins/board/client/assets/bots`, loaded with `include_bytes!` from that path (the React client is frozen, so the files stay), picked by FNV-1a of `agentId` mod 20 (init `2166136261`, multiply `16777619`, 32-bit). A running card's avatar comes from `running_avatar` in `src/card.rs`, which shows the running spinner in this part; TASK-193 replaces its body with the orb.
- The view switch shows Runs, Timeline, and Recaps. In this part, Timeline and Recaps render "Loading…" from `BoardView::Timeline` and `BoardView::Recaps` arms in `src/page.rs`; TASK-193 fills them.
- Icons: the sidebar item uses `IconName::Columns3`, the subagent elbow `IconName::CornerDownRight`, the rail device `IconName::Laptop` for names with macbook, laptop, or notebook, else `IconName::HardDrive`, and diffs off `IconName::PencilOff` (TASK-195).
- Look: tokens from `bachuc_theme` with Electron's names (`surface0`, `surface1`, `surface2`, `border`, `foreground`, `foreground_muted`, `accent`, `status_warning`, `status_danger`, `status_success`); hue colors from the pure color functions as `Hsla`. Copy the Runs measures in Design line by line: card radius 8, control radius 6, column gap 24, rail height 40, seen opacity 0.5. Pulses: 700 ms in and out, opacity 1 to 0.35. Tabular digits for counts and times.
- Lists render lazily: each Runs column is a GPUI `list` with one item per cluster; an expanded cluster's child rows are their own items. Keep items small (`MEMORY.md`, 2026-10-15).
- The elapsed clock redraws once per second only while a running card is in view. Never toggle `display` from hover: card actions swap by visibility.
- Every card, button, tab, and row gets a role and a label; the card label is "`title, label[, seen|, new]`" (page 580). The keyboard focus ring is 2 px `accent`.
- Keep each rule in a pure function and unit-test it (`MEMORY.md`, 2026-10-16). Reproduce JS rounding: `Math.round` rounds halves up.

Expected result:

- With board listed enabled and `Running`, the sidebar shows "Board"; it and `Mod+D` open the Board page with Runs, Timeline, and Recaps tabs and the size control.
- Runs shows the active host's lane with Running and Just finished columns, clusters with subagents, stars, diffs toggles, Remove, and the TASK chip.
- Cases:
  - `board_poll_interval`: any running run -> 2,000 ms; none -> 15,000 ms.
  - `group_runs` keeps first-seen project order and puts starred runs first in each project.
  - `build_run_trees` with a missing parent -> the child is a root; with a parent cycle -> both runs are roots, each once.
  - `board_columns` puts a tree with any running run in Running, and sorts finished trees starred first, then newest `ended_at`.
  - `remove_finished_run`: removed at once -> true; not removed and the run is gone on re-read -> true; same `observingSince` -> false; fresh scope -> the second call's result.
  - `allocate_colors` with `{a: 0}` and ids `[b]` -> `b` gets 180; existing hues never change.
  - `clamp_board_size(5)` -> 10; `(250)` -> 200; `board_scale(100)` -> 0.7.
  - `connection_state`: each of the five states.
  - `avatar_index` is stable for one id and inside 0..20.
  - `chip_colors(None)` -> theme colors; `chip_colors(Some(200))` -> the hue colors.
  - `is_dark_surface` and `repo_label` light and dark lightness.
  - A snapshot equal to the last one -> no state change and no redraw.

Anti-goal: one store sends at most one `board.snapshot` per `board_poll_interval` (2,000 ms with a running run, 15,000 ms without; lead, from the spec check), never two at once, and none after deactivation; tripwire; read from the `poll_due` and in-flight guard tests when the store lands and at completion, and by reading that views hold no poll of their own.
