# TASK-184 edit-diffs plugin

Group: H (writes `plugins/edit-diffs` and `crates/timeline`; runs after TASK-178 in the same group)
Class: risky

## Brief

Goal: Port the edit-diffs client to a native plugin crate and move the hard-coded edit row out of `crates/timeline`, so edit diffs show only when the host runs edit-diffs and the thread has not turned them off.

Change: `crates/timeline` draws every edit and write call as a built-in diff row -> the `bachuc-plugin-edit-diffs` crate transforms those calls into `edit-diff` items, draws them, adds the "Edit diffs" settings screen and the thread toggle, and the timeline falls back to a plain tool call row.

Design: the React client in [hiep-plugins/plugins/edit-diffs/index.client.tsx](hiep-plugins/plugins/edit-diffs/index.client.tsx) (lines 8-51) with [hiep-plugins/plugins/edit-diffs/client/edit-row.tsx](hiep-plugins/plugins/edit-diffs/client/edit-row.tsx) (settle lines 39-49, `displayPath` 51-59, `headerLabel` 61-67, locate 69-94, `DiffRow` 96-144, `DiffBody` 146-201, `EditDiffRow` 203-302), [hiep-plugins/plugins/edit-diffs/client/highlight.ts](hiep-plugins/plugins/edit-diffs/client/highlight.ts), [hiep-plugins/plugins/edit-diffs/client/settings.tsx](hiep-plugins/plugins/edit-diffs/client/settings.tsx), and the shared logic in [hiep-plugins/plugins/edit-diffs/shared/diff.ts](hiep-plugins/plugins/edit-diffs/shared/diff.ts), [shared/change-bar.ts](hiep-plugins/plugins/edit-diffs/shared/change-bar.ts), [shared/edit-item.ts](hiep-plugins/plugins/edit-diffs/shared/edit-item.ts), [shared/contracts.ts](hiep-plugins/plugins/edit-diffs/shared/contracts.ts), [shared/settings.ts](hiep-plugins/plugins/edit-diffs/shared/settings.ts), and [shared/thread-mode.ts](hiep-plugins/plugins/edit-diffs/shared/thread-mode.ts). The GPUI row to remove is `render_edit` in [packages/desktop-gpui/crates/timeline/src/tool_view.rs](packages/desktop-gpui/crates/timeline/src/tool_view.rs) (line 656), called from `render_step` (`lib.rs:1689-1693`), with its diff cache in `update_hashes` (`lib.rs:604-632`).

Expected result:

- With the crate registered and edit-diffs running on the host, each edit and write call in a step shows the plugin row, open by default, with the same header, bar, counts, and hunks as Electron.
- The command item turns the thread's diffs off; the calls then show as plain tool call rows, and on again.
- Cases:
  - `labels["edit-diffs.mode"] == "off"` -> the transformer returns `None`.
  - A `tool_call` of `detail.type: "read"` -> `None`.
  - A write with `content: "a\nb\n"` -> one hunk, two add rows numbered 1 and 2.
  - `lineDiff` of 600 by 600 lines -> the fallback: all removes, then all adds.
  - A Codex bare `@@` diff -> hunks without starts; expanded -> one locate request after 300 ms; collapsed -> none.
  - Status `running` -> "Editing"/"Writing"; `failed` -> "Edit failed" in `status_danger`; `completed` -> no label.
  - Settings `Invalid` -> "Reset to defaults" calls `reset`; a save `Conflict` keeps the switch value and shows `save_error`.
  - `changeBar(3, 1)` and `changeBar(100, 1)` -> the same squares as the TS tests.
  - Without the plugin, an edit call in a step -> a plain tool call row, always visible.

Anti-goal: a 1,000-line by 1,000-line edit builds its hunks and numbered rows in under 50 ms in a debug test (the 250,000-cell fallback, as Electron), and the timeline no longer builds edit diffs in a flush: `rg -n "render_edit|hidden_diffs|toggle_diff" packages/desktop-gpui/crates/timeline/src` has no match; tripwire; read after the logic port and at completion.
