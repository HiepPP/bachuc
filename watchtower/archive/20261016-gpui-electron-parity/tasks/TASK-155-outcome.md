## Lessons

- In a test module of a file that globs `gpui_kit::*`, `use super::*` imports gpui's `test` macro. `#[test]` then fails with "recursion limit reached". Import the needed names.
- GPUI cannot remove one key binding, and `clear_key_bindings` also drops the gpui-kit keys. To rebind, add `KeyBinding::new(keys, gpui_kit::Unbind(action_name), ctx)` for each old binding, then add the new bindings (`actions.rs` `rebind`).
- `Workspace::open` with an open key replaces the view in place and focuses that group. The app gives every tab a `pane:N` key, so new tab, draft, and agent replace each other in place. `identity` (`agent:<id>`, `file:<abs path>`, `diff:<abs path>`) finds an open tab.
- `PaneEvent::Activated` comes after a batch of opens. Check that the key is still active before loading a lazy tab.
- `Workspace` emits `Activated` only for the focused group. A lazy agent tab that becomes active in another group shows "Loading agent" until it is clicked.
- The window uses `app_owns_titlebar_drag: true`. Only the app's own rows (sidebar title row, header, settings title row) move the window, through `start_window_move`. Chrome buttons stop mouse-down propagation.

## Questions

- `bachuc-sidebar` keeps its width in a private field. The sidebar remembers its width only while the app runs. A persisted width needs `Sidebar::width` and `Sidebar::set_width` in the sidebar crate. The Explorer width persists in `layout.json`.
- `bachuc-workspace` has no per-tab context menu. Rename agent and Archive agent are in the header "Workspace actions" menu, for the active agent tab. Electron's tab menu needs a `Workspace` tab-menu builder API.
- The Electron tab bar and Explorer rail are drag areas, but those crates own their rows. Only the app rows drag the window.
- Retry in the host gate makes a new client, which closes the old host's tabs, as a host switch does. The client also retries by itself.
- Agents started outside the app get a tab when their workspace is opened again. Tabs are not added live.
- User images in the timeline still need a local store (TASK-149 lesson); not in this spec.
- `crates/composer` had uncommitted changes from another worker during this run (`composer.rs`, `slash.rs`, `assets/`). This TASK did not touch them.
