# GPUI client accessibility audit

Audit of `Bachuc GPUI.app` through the accessibility (AX) tree, read with `cua_repl` `getAXState`, on live (`ws://127.0.0.1:6768/ws`), 2026-10-16. The VoiceOver pass is a manual check and is `UNVERIFIED (unattended)`.

Result: every element in scope has a role and a label in the AX tree. The gaps are in popover items, terminal output, and two label details. VoiceOver reading of the sidebar, the timeline, and the composer is not verified, so the [ADR-0034](../../../watchtower/decisions/ADR-0034-rust-gpui-client-over-swift-and-electron.md) `Revisit If` condition stays open until a human runs it.

## Notes from the walk

- Click targets answer `click` by index: sidebar rows, tabs, `New agent`, `New terminal`, host switcher. The tree lags the draw, so a click can look like it did nothing. Two `New terminal` clicks and Cmd+T made three terminals in this run; the first tree read after a click showed no tab.
- The `Cancel new agent` click did not close the dialog in the tree after 2 s; Escape did. Treat this as unverified (lag), not a gap.
- The dialog and menu popover open as `dialog`, so they are announced.

## How to re-run

1. Build the bundle only if `packages/desktop-gpui/target/bundles/Bachuc GPUI.app` is missing: `packages/desktop-gpui/bundle.sh bin bachuc-desktop "Bachuc GPUI" io.github.hieppp.bachuc-desktop`.
2. Take the screen lock, then open the bundle and keep it in front: `open "<bundle>"` in a loop every 2.5 s. GPUI draws only while its window is in front.
3. Make test agents on live: a mock agent (`npm run cli -- run --provider mock --model thirty-minute-stream --cwd /tmp/gpui-bench -d -q "start bench"`) and a claude agent in `default` mode asked to use the Write tool (for the permission buttons).
4. In `cua_repl`, wrap each step in `Promise.race` with a timeout and pass `timeout_ms`. Read `getAXState({disableDiffing:true, emit:false})` twice, and look elements up by label, not index. Do not click the title bar.
5. Walk in this order: sidebar, host switcher (click it, then click it again), mock agent tab (timeline, steps), claude agent tab (permission buttons, composer, mode pill with Escape to close), `super+n` for the new-agent dialog (Escape to close), `super+t` for a terminal tab.
6. Compare each row of the Report table with the tree. A pass row must show its label.
7. Clean up on live: `permit allow <id> --all`, `stop` and `archive` each agent, `terminal kill` each terminal, quit the app, then release the lock.
8. Manual: turn on VoiceOver with Cmd+F5, move through the sidebar, a timeline message, and the composer, and record what it reads. Turn VoiceOver off with Cmd+F5.
